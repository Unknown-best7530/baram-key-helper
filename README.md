# 바람의나라 단축키 도우미

바람의나라 플레이를 위한 단축키·타이머·메모 도우미

## 다운로드 및 실행 방법

1. **[GitHub Releases에서 업데이트 내용 확인 및 최신 버전 다운로드](https://github.com/Unknown-best7530/baram-key-helper/releases/latest)**
2. 최신 Release에 첨부된 `baram_key_helper.exe` 다운로드 후 실행
3. Windows UAC 확인 창이 나타나면 게임에서 안정적으로 사용하기 위해 **[예]** 선택

- 별도의 Python 설치 없이 실행 가능
- 최신 업데이트 내용과 SHA-256 값은 Releases 페이지에서 확인

---

## 실행 전 주의사항

### 전역 단축키와 입력

본 프로그램은 Windows 전체에서 단축키와 입력을 감지함

- 문서 작성, 웹 브라우징, 다른 게임 이용 중에도 설정한 입력이 동작할 수 있음
- 게임 외 작업 시 전체 기능을 끄거나 프로그램 종료 권장

### 다운로드 및 SmartScreen 경고

- Edge에서 다운로드 경고가 표시되면 다운로드 메뉴에서 파일 보관을 선택하거나 다른 브라우저 이용
- `'Windows의 PC 보호'` 경고가 표시되면 Releases의 SHA-256 값을 먼저 확인
- 확인 후 `[추가 정보]` → `[실행]` 선택

---

## 핵심 기능

- 키보드·마우스 입력 매핑 및 복합·횟수별 출력
- 완료 알림과 선택적 자동 출력을 지원하는 쿨타임 타이머
- 스톱워치 및 주기 커스텀
- 경험치 계산, 메모장, 화면 돋보기, 게임 화면 상태 표시
- 모드별 설정 저장
- Basic / Standard / Pro 플랜 및 Pro 7일 무료 체험

---

## 입력 설정 안내

키보드와 마우스 입력은 모든 기능에서 같은 `입력 설정` 창으로 등록함

- 키 또는 조합키는 바로 누른 뒤 모두 떼서 입력
- 마우스는 파란 입력 영역에서 클릭 또는 휠을 사용해 입력
- Ctrl / Shift / Alt + 마우스 조합도 입력 가능
- 타이머 입력은 타이머 창이 열려 있을 때만 동작
- 매핑 출력은 `기본 출력` 또는 `횟수별 출력`을 선택하고, 같은 화면에서 키·마우스 출력 단계를 바로 편집

## 설정 파일 위치

프로그램 설정과 메모 데이터는 아래 경로에 자동 저장됨

```text

```
