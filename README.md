# 바람의나라 단축키 도우미

바람의나라 단축키·타이머·메모 도우미

## 다운로드 및 실행 방법

1. 우측의 **[Releases](https://github.com/Unknown-best7530/baram-key-helper/releases/latest)** 페이지로 이동
2. 최신 버전의 `baram_key_helper.exe` 파일 다운로드
3. 원하는 폴더에 보관한 뒤 실행 (별도의 Python 환경 설치 필요X)

---

## 실행 전 주의사항 (필독)

### 1. 전역(Global) 단축키 동작 주의
본 프로그램은 특정 게임 창에 국한되지 않고 **Windows 전체 시스템(전역)에서 단축키 및 키 입력을 감지**
- **주의**: 웹 브라우징, 타자 입력, 문서 작성, 타 게임 플레이 시 의도치 않은 단축키가 작동할 수 있음
- **조치**: 게임 플레이 외 작업 시에는 **프로그램의 단축키 작동을 비활성화(Off)하거나 프로그램을 종료** 후 사용하기를 권장

### 2. Windows SmartScreen (파란색 경고창) 발생 시
개인 개발자가 배포하는 미서명 프로그램 특성상 'Windows의 PC 보호' 경고 창이 발생할 수 있음
- **조치 방법**: 경고창의 **`[추가 정보]`**를 클릭한 후 나타나는 **`[실행]`** 버튼을 클릭하여 실행하길 바람

### 3. 관리자 권한 실행
바람의나라 게임 클라이언트가 관리자 권한으로 실행 중인 경우, 본 프로그램도 입력 신호를 정상 전달하기 위해 관리자 권한이 필요
- **조치 방법**: `baram_key_helper.exe` 파일 **`우클릭 -> 관리자 권한으로 실행`**을 권장

## 주요 기능

- 키보드 및 마우스 입력 매핑
- Shift / Ctrl / Alt 조합 입력 딜레이 설정
- 단축키 기반 쿨타임 타이머와 스톱워치
- 경험치 계산, 표 형식 메모, 화면 돋보기 기능
- 모드별 개별 설정 저장 및 반복/순차 입력 지원

## 설정 파일 위치

프로그램 설정 및 메모 데이터는 실행 파일과 분리되어 각 사용자 계정의 아래 경로에 자동 저장

